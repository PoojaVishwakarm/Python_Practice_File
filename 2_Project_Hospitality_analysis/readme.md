# 🏨 Hospitality Analytics Data Analyst Portfolio Project

This project represents a **complete, industry-standard, end-to-end data analytics workflow**, designed to mirror the real responsibilities of a **professional Data Analyst** working in the **hospitality domain**.

It demonstrates how raw hotel data can be transformed into **actionable business insights** through data preparation, analysis, visualization, and reporting.

---

## 📌 Project Overview

The objective of this project is to analyze **hotel occupancy and revenue performance** across cities, room categories, and time periods to support **data-driven business decisions**.

This project simulates a **corporate-grade analytics workflow**, covering:

✅ Data preparation & exploratory data analysis (Python)  
✅ Business-driven analysis using SQL  
✅ Interactive dashboard development in Power BI  
✅ Insight reporting and stakeholder-ready presentation  

---

## 🛠️ Tools & Technologies Used

- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **Jupyter Notebook**
- **SQL** (MySQL / PostgreSQL / SQL Server)
- **Power BI**
- **GitHub**

---

## 🔄 Project Workflow

1️⃣ **Data Ingestion**  
- Imported raw hospitality datasets into Python  
- Performed initial data validation and inspection  

2️⃣ **Data Cleaning & Preparation**  
- Handled missing values and duplicates  
- Standardized date formats  
- Cleaned categorical and numerical fields  

3️⃣ **Exploratory Data Analysis (EDA)**  
- Occupancy rate analysis by room category  
- City-wise hotel performance comparison  
- Weekday vs weekend occupancy analysis  
- Monthly and seasonal trend analysis  

4️⃣ **Business Insight Generation**  
- Identified top-performing cities and hotels  
- Analyzed revenue contribution by room category  
- Evaluated demand patterns across time periods  

5️⃣ **Visualization & Reporting**  
- Built an interactive python library 
- Designed trend charts, and filters  
- Translated insights into business recommendations  

---

## 📊 Business Questions Answered

- What is the **average occupancy rate by room category**?
- Which **city generates the highest revenue**?
- Is occupancy higher on **weekdays or weekends**?
- How does **monthly occupancy and revenue trend** change?
- Which room categories contribute most to total revenue?

---

## 📈 Key Insights

- Weekend occupancy is consistently higher than weekdays, indicating strong leisure demand  
- Certain cities outperform others in both occupancy and revenue  
- Premium room categories generate higher revenue despite lower occupancy  
- Clear seasonal trends can help improve demand forecasting and pricing strategies

The Power BI dashboard includes:

*Designed for business stakeholders and decision-makers.*
